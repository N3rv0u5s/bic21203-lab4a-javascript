## Overview
This repository contains solutions for Lab 4a demonstrating JavaScript DOM selection, event handling with `addEventListener()`, input validation using conditional statements, and dynamic element creation with `for` loops.

## Instructions to Run
1. Clone or download this repository.
2. Open `Q1/index.html`, `Q2/index.html`, or `Q3/index.html` in any modern desktop web browser (or via VS Code Live Server).

## Outputs
- **Q1:** Replaces text with "Hello there!" upon clicking the button.
- **Q2:** Validates numeric input and compares values against 10.
- **Q3:** Dynamically generates an ordered list from 1 to 5 without duplicating items on repeated clicks.
